# Campus Wellbeing Trend & Referral Dashboard

**Ministry of Education — Department of Higher Education Hackathon (PS10)**

An anonymous, opt-in wellbeing check-in system for campuses. It aggregates
mood/workload self-reports into trend charts, and applies a conservative,
fully documented rule to route concerning *patterns* (never diagnoses) to
human counselors for review.

> Synthetic demo data only. This system never generates a diagnosis or
> self-harm related content — see [`docs/privacy_and_safety.md`](docs/privacy_and_safety.md).

## What's inside

- **Anonymous check-in** — pseudonym + two 1–5 scores (mood, workload), no free text, no names.
- **Aggregate trend dashboard** — weekly mood/workload charts, cohort-level only.
- **Conservative flagging rule** — two documented, transparent rules (see [`docs/flagging_rule.md`](docs/flagging_rule.md)).
- **Counselor review queue** — every flag requires a human decision (reviewed/dismissed).
- **Privacy & safety page** — plain-language summary of the safeguards in place.

## Running locally

### 1. Backend

```bash
cd backend
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# (Optional) regenerate the synthetic dataset
python -m utils.synthetic_data_generator

uvicorn main:app --reload --port 8000
```

The API is now at `http://localhost:8000`. Interactive docs at
`http://localhost:8000/docs`.

### 2. Frontend

In a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173`. In development, Vite proxies `/api/*`
requests to the backend on port 8000 (see `frontend/vite.config.ts`) —
no extra configuration needed.

### 3. Try it out

1. Go to **Check in**, submit a few check-ins under different pseudonyms.
2. Go to **Trends** to see the aggregate dashboard update.
3. Go to **Counselor review**, click **Recompute flags** — the pre-loaded
   synthetic dataset already contains a few pseudonyms that trip the
   flagging rule, so you should see entries immediately.
4. Go to **Privacy & safety** for the plain-language safeguards summary.

## Guardrails baked into the design

- No names, emails, IDs, or free-text notes are ever collected.
- The flagging rule is conservative (requires a sustained pattern, not a single bad day) and fully documented — no black-box model.
- Every flag routes to a human counselor; nothing is ever automatically actioned or sent to a student.
- The system never produces a diagnostic label or self-harm related content, anywhere.
- All data in this repository, including the pre-loaded dataset, is synthetic.
