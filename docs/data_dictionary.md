# Data Dictionary

## `backend/data/synthetic_checkins.csv`

Synthetic seed data, generated by `backend/utils/synthetic_data_generator.py`.
One row = one check-in.

| Column        | Type            | Description                                                                 |
|---------------|-----------------|-------------------------------------------------------------------------------|
| `id`          | integer         | Sequential check-in ID, unique across the dataset.                            |
| `pseudonym_id`| string          | Opaque pseudonym, format `anon-<word>-<number>`. Not a real identifier.       |
| `mood`        | integer (1–5)   | 1 = very low, 2 = low, 3 = neutral, 4 = good, 5 = very good.                   |
| `workload`    | integer (1–5)   | 1 = very light, 2 = light, 3 = moderate, 4 = heavy, 5 = overwhelming.          |
| `note_tag`    | string or empty | One of: `exams`, `assignments`, `sleep`, `social`, `family`, `sports`, `part_time_job`, or empty. |
| `timestamp`   | ISO 8601 string | UTC timestamp of the check-in (naive, no timezone suffix).                   |

### Synthetic dataset shape

- **40 pseudonymous students**, **10 simulated weeks** (semester-length).
- 1–3 check-ins per student per week.
- A **mid-semester dip** (weeks 6–8) is baked in for most of the cohort —
  this is what produces the visible "stress spike around mid-sem" on the
  aggregate trend chart.
- **3 pseudonyms** are given a sustained (not just mid-sem) low-mood /
  high-workload pattern from week 5 onward, so the flagging rule has
  genuine positives to demonstrate in the Counselor review queue.

## API request/response models (`backend/models/schemas.py`)

### `CheckInCreate` (POST body for `/api/checkins`)

| Field          | Type            | Constraints                                  |
|----------------|-----------------|-----------------------------------------------|
| `pseudonym_id` | string          | 4–64 chars, must not contain `@`               |
| `mood`         | integer         | 1–5                                            |
| `workload`     | integer         | 1–5                                            |
| `note_tag`     | string, optional| max 32 chars                                   |

### `WeeklyTrendPoint` (GET `/api/dashboard/trends`, one item)

| Field            | Type    | Description                                  |
|------------------|---------|-----------------------------------------------|
| `week_label`     | string  | e.g. `"Week 1"`                                |
| `week_start`     | date    | ISO date of the week's Monday                 |
| `avg_mood`       | float   | Mean mood across all check-ins that week      |
| `avg_workload`   | float   | Mean workload across all check-ins that week  |
| `checkin_count`  | integer | Number of check-ins that week                 |

### `SummaryMetrics` (GET `/api/dashboard/summary`)

| Field                    | Type          | Description                                  |
|--------------------------|---------------|-----------------------------------------------|
| `total_checkins`         | integer       | All-time check-in count                       |
| `unique_pseudonyms`      | integer       | Distinct pseudonyms seen                      |
| `avg_mood_last_7d`       | float or null | Mean mood, last 7 days                        |
| `avg_workload_last_7d`   | float or null | Mean workload, last 7 days                    |
| `pct_low_mood_last_7d`   | float or null | % of last-7-day check-ins with mood ≤ 2        |
| `active_flags`           | integer       | Flags currently `pending_review`              |

### `FlagRecord` (GET `/api/flags`, one item)

| Field                 | Type    | Description                                            |
|-----------------------|---------|----------------------------------------------------------|
| `flag_id`             | integer | Unique flag ID                                            |
| `pseudonym_id`        | string  | The flagged pseudonym                                     |
| `created_at`          | datetime| When the flag was created                                  |
| `reasons`             | list    | `{rule, detail}` objects — see `docs/flagging_rule.md`     |
| `checkins_considered` | integer | Check-ins in the 14-day window used for evaluation         |
| `status`              | string  | `pending_review` \| `reviewed` \| `dismissed`              |
| `counselor_note`      | string or null | Optional internal note left by a counselor          |
| `reviewed_at`         | datetime or null | When the flag was reviewed/dismissed              |
