# Campus Pulse UI Redesign

The frontend uses a privacy-first visual system designed specifically for the Campus Wellbeing Trend & Referral Dashboard.

## Visual language
- Deep navy foundation for trust and focus
- Soft teal for wellbeing/campus signals
- Warm amber for attention and workload context
- Layered glass surfaces and subtle grid textures
- Motion is used for hierarchy and feedback, not decoration

## Interaction principles
- Aggregate signals are visually distinct from individual review workflows.
- Counselor review always remains human-led.
- Pseudonymous IDs are used in review surfaces.
- The check-in flow reinforces opt-in and privacy.
- Reduced-motion preferences are respected.

## Demo safety
All preloaded dashboard data is synthetic. The UI does not provide diagnostic labels or self-harm-related content.
